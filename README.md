# MediCare 🏥

MediCare is a full-stack hospital and healthcare management platform designed to simplify the process of booking and managing medical appointments.

The platform provides patients with an easy way to find doctors, book appointments, and track appointment status, while administrators can manage doctors and handle patient appointments through an admin dashboard.

## 🚀 Features

- 🏥 Modern Hospital & Healthcare Website
- 👨‍⚕️ Dynamic Doctor Listing
- 🔍 Doctor Details & Specialization
- 📅 Online Appointment Booking
- ⏰ Doctor Availability & Time Slots
- 🚫 Prevents Double Booking
- 👤 Patient Appointment Tracking
- 📊 Appointment Status — Pending, Confirmed & Cancelled
- 🔐 Admin Login & Authentication
- 🛠️ Admin Appointment Management
- 👨‍⚕️ Doctor Management
- 🖼️ Doctor Profile Image Upload
- 📱 Responsive User Interface
- 🤖 AI Assistant Support
- 🗄️ PostgreSQL Database
